# 🌐 Udit Dadhich — Developer Portfolio

A premium animated developer portfolio built using React, Vite, Tailwind CSS, and Framer Motion.

🔗 Live Website: https://portfolio-1inz.vercel.app/#

---

## ✨ Features

- Modern premium UI/UX
- Fully responsive design
- Animated sections using Framer Motion
- Interactive skill cards
- Live GitHub profile integration
- Live LeetCode stats
- Smooth scrolling effects
- Glassmorphism design
- 3D hover effects
- Coding profiles section
- Project showcase section
- Contact section

---

## 🛠️ Tech Stack

### Frontend
- React.js

- React Icons

## 🚀 Installation & Setup

Clone the repository:

```bash
git clone https://github.com/UditDadhich/Portfolio.git
```

Move into project folder:

```bash
cd Portfolio
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
